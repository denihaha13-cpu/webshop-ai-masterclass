# Bouw het brein van je webshop

Een gratis, interactieve masterclass die draait **IN Claude Code**. In 45 minuten bouw je het **brein van je webshop** — een levende kennisbank (LLM-wiki) die je AI alles over jouw shop leert. Daarna doet je AI het werk: klantvragen, landingspagina's, advertenties, productteksten, mails. Geen voorkennis nodig. Als je kunt typen, kun je dit.

**LIO — The AI Operator × 187N** · door Leon (@lio · @liogpt · @187n)

---

## Stap 1 — Installeer Claude Code

**Mac / Linux:**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://claude.ai/install.ps1 | iex
```

Eerste keer? Na installatie type je `claude` en volg je de setup (login of API key).

---

## Stap 2 — Installeer de Masterclass

**Mac / Linux:**
```bash
curl -fsSL https://raw.githubusercontent.com/novusordos666/webshop-ai-masterclass/main/install.sh | bash
```

**Windows (PowerShell):**
```powershell
irm https://raw.githubusercontent.com/novusordos666/webshop-ai-masterclass/main/install.ps1 | iex
```

## Stap 3 — Start de Masterclass

Open Claude Code (type `claude`) en typ dan:

```
/webshop:masterclass
```

Dat is het. Claude neemt het over en leidt je stap voor stap. 🚀

## De 16 skills die je overhoudt

Allemaal in de `/webshop:` verzameling. Elke skill leest je brein — dus alles klinkt vanzelf als jóuw shop.

**🎧 Klantenservice** — `klantenhulp` · `review-reactie` · `klacht-sussen` · `vraagbaak`
**📣 Marketing & Ads** — `scroll-stop` · `social-set` · `actie-kalender` · `static-ad` ⚡
**🛍️ Winkel & producten** — `productverhaal` · `vindbaar` · `winkelpagina` · `bundel-bouwer` · `prijs-slim`
**🔁 Retentie** — `mandje-redden` · `welkom-reeks` · `mail-magneet`

⚡ = power-up die de Higgsfield-connector nodig heeft (AI-advertentiebeeld). De rest werkt volledig offline.

**Het brein bouw je als allereerste — daarna maakt elke skill vanzelf on-brand werk.**
