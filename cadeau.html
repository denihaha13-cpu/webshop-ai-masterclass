Zo installeer je het

Eén commando, en je bent klaar

Je hebt alleen Claude Code nodig (Mac of Windows).

Installeer Claude Code

Heb je het nog niet? Open de Terminal (Mac) of PowerShell (Windows), plak dit en typ daarna claude om in te loggen.

# Mac
curl -fsSL https://claude.ai/install.sh | bash
# Windows
irm https://claude.ai/install.ps1 | iex

Installeer het cadeau

Plak dit commando. Het zet alle 16 skills op je laptop.

# Mac
curl -fsSL https://raw.githubusercontent.com/novusordos666/webshop-ai-masterclass/main/install.sh | bash
# Windows
irm https://raw.githubusercontent.com/novusordos666/webshop-ai-masterclass/main/install.ps1 | iex

Open Claude Code

Typ claude in een map die je terugvindt, bijvoorbeeld je Documenten. Daar komt je map webshop-brein/ te staan.

Typ: /webshop:masterclass

LIO neemt het vanaf hier over en helpt je één stap tegelijk.
